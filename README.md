# veille_grok-claude

Pipeline de veille **IA × Géomatique** : Grok produit les briefs, un agent Claude les organise.

## Structure

```
veilles/
  2026-10-02_geoai.md   # Brief du 30 sept. → 2 oct. 2026
  2026-10-03_geoai.md   # Complément 1–3 oct. 2026 (Altair-1, FAME, TESSERA, AAG)
  2026-10-04_geoai.md   # Complément 2–4 oct. 2026 (Earth splats, GeoAgent, GEE AI, EarthPV)
  2026-10-05_geoai.md   # Complément 3–5 oct. 2026 (supervision géographique, GeoAI.js, Antarctique, LiDAR orbital)
```

## Convention

- Un fichier markdown par fenêtre de veille (`YYYY-MM-DD_theme.md`)
- Format attendu par Claude : **Résumé** + **Pertinence** + **Actions** + sources
- Repo **privé** — destinataire unique : agent Claude d’organisation
