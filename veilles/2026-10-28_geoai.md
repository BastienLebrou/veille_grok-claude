## 1. CARTO AI Lab + PlacePulse Embeddings (27 octobre)

**Résumé**  
CARTO a lancé son AI Lab le 27 octobre pour rapprocher geospatial foundation models, analytics sur embeddings et Agentic GIS. Premier modèle issu du Lab : PlacePulse (en collaboration avec Applied Geographic Solutions). Il produit un vecteur unique de 256 dimensions pour chaque cellule H3 résolution 7 peuplée aux États-Unis (environ 1,06 million de cellules). Chaque vecteur compresses des centaines de variables structurelles (572 attributs AGS étendus à ~2 288 features avec contexte de voisinage : démographie, activité économique, patterns de commuting, revenu, risques climatiques, etc.) via apprentissage auto-supervisé. Non spécialisé sur une tâche unique → réutilisable pour similarité, clustering, prédiction. Paper arXiv disponible. Embeddings en private preview dans CARTO Workflows via l’extension Analytics on Embeddings.

**Pertinence**  
Un des premiers foundation models « structurels » (données socio-économiques / environnementales de lieu, pas uniquement imagerie) opérationnalisé pour des décisions business et territoriales. Illustre comment les embeddings de lieux deviennent des features directement exploitables par agents et analystes. Complémentaire des modèles purement EO (OlmoEarth, AlphaEarth Foundations). Très pertinent pour qui travaille sur site selection, market expansion, détection d’écarts d’infrastructure ou agents GIS.

**Actions recommandées**  
1. Lire le paper « PlacePulse: Learning Transferable Place Representations from Structural Geographic Data » (arXiv:2610.13390) et le billet CARTO.  
2. Demander l’accès private preview PlacePulse et tester Similarity Search / clustering / prediction dans CARTO Workflows sur un cas concret (retail, EV charging, assurance, etc.).  
3. Comparer les résultats avec Google’s Population Dynamics Foundation Model sur des tâches similaires (santé, économie vs POI / géographie physique).

## 2. OlmoEarth v1.3 (Ai2) : embeddings planétaires 10 m + Explorateur gratuit (22 octobre)

**Résumé**  
Ai2 a publié OlmoEarth v1.3, un modèle d’embeddings satellite state-of-the-art. Il lit une année de séries temporelles multimodales (Sentinel-1 radar + Sentinel-2 + Landsat) et produit un vecteur 128-dimensionnel (les 64 premières dimensions fonctionnent aussi seules) par pixel 10 m. Embeddings annuels précalculés pour l’ensemble de la planète (couverture 2023-2025 globale ; 2017-2022 sur pays sélectionnés) disponibles sur Source Cooperative. Explorateur web sans inscription ni GPU : visualisation fausse couleur, comparaison d’années, recherche de lieux similaires, entraînement d’un petit classifieur sur quelques points labellisés, export GeoTIFF. Poids, code et data open sous licence OlmoEarth Artifact. Surpasse AlphaEarth Foundations et Tessera v2 sur 20/27 évaluations.

**Pertinence**  
Actuellement l’une des portes d’entrée les plus accessibles et immédiates au GeoAI foundation-model. Permet de prototyper des cartes de cultures, de changement, de similarité ou de classification sans GPU ni téléchargement massif d’imagerie. Idéal pour valider un use-case avant fine-tuning ou pipeline production. Exemple concret de « compute once, reuse everywhere ».

**Actions recommandées**  
1. Ouvrir immédiatement l’Explorateur : https://olmoearth.allenai.org/embeddings et tester sur une zone connue (changement temporel, similarité, mini-classifieur).  
2. Télécharger quelques tuiles d’embeddings et entraîner un classifieur léger localement (scikit-learn, XGBoost, etc.).  
3. Lire le technical report / arXiv (2610.32294) et comparer avec AlphaEarth Foundations sur le même AOI.

## 3. MAPL-EMIT (Google + NASA) – couverture renforcée (26 octobre)

**Résumé**  
Article du 26 octobre mettant en avant MAPL-EMIT, le modèle Swin-v2 développé par Google Research et NASA. Entraîné sur 3,6 millions de panaches synthétiques (modèle Lagrangian puff + HITRAN) injectés dans des tuiles EMIT réelles, il détecte environ 50 % de panaches de méthane plausibles de plus que les analystes humains sur 1 084 scènes. Fournit enhancement, masque et localisation de source. Catalogue disponible sur Earth Engine, poids et données synthétiques sur Kaggle, code d’inférence sur GitHub. Paper PNAS.

**Pertinence**  
Cas d’usage très concret et ouvert de deep learning sur données hyperspectrales pour un enjeu climatique prioritaire (méthane). Montre la valeur combinée de données synthétiques physiques + architecture qui capture spectre + forme spatiale. Outils réutilisables pour d’autres polluants ou phénomènes.

**Actions recommandées**  
1. Visualiser le catalogue MAPL-EMIT dans Google Earth Engine.  
2. Tester le code d’inférence (GitHub google-research/mapl) ou les poids Kaggle si vous travaillez sur émissions / monitoring atmosphérique.  
3. Adapter l’approche simulation + vision transformer à un autre gaz ou signature spectrale.

## 4. GenAI pour visualisation de scénarios d’aménagement (Transactions in GIS, 25 octobre)

**Résumé**  
Publication du 25 octobre : « Generative Artificial Intelligence for Planning Scenario Visualization: A Framework and Benchmark for Controllable Street-Level Image Synthesis » (Qian Cao et al., University of Georgia / University of Texas at Austin). Framework interactif GenAI + humain pour synthétiser des images street-level contrôlables de scénarios d’aménagement (ex. grandes installations photovoltaïques) tout en préservant le contexte géographique. Benchmark de 11 configurations sur 6 modèles GenAI ; dataset before-and-after national ; code GitHub annoncé.

**Pertinence**  
Pont concret entre GenAI multimodale et pratiques d’urbanisme / planification spatiale. Utile pour communication de projets, digital twins, participation citoyenne ou visualisation rapide dans QGIS / ArcGIS.

**Actions recommandées**  
1. Lire le paper : https://doi.org/10.1111/tgis.70431  
2. Suivre le dépôt GitHub QianC95/planning-scenario-visualization pour le code et les ressources.  
3. Expérimenter un workflow similaire avec le plugin QGIS GeoPrompt Urban Scenario Visualizer ou des modèles de diffusion + ControlNet sur une zone locale.
