## 3. Paper arXiv (3 nov.) : cartographie land-cover haute résolution cohérente avec GeoAI sur séries temporelles NAIP

**Résumé**  
Paper soumis le 3 novembre 2026 : « Using GeoAI and machine learning tools for consistent high-resolution land cover mapping based on time-series NAIP imagery » (Liu et al.). Workflow dual-track pour produire des cartes land-cover 1 m temporellement cohérentes à partir d'imagerie NAIP sans échantillons historiques. Pour 2009-2017 : U-Net/ResNet-34 pré-entraîné + raffinement boundaries avec Segment Anything Model (SAM). Pour 2004-2008 : bridging spatiotemporel NLCD + label back-casting. Accuracies ~0.887 (2014/2017) et 0.733 (2004) sur counties NC/PA. Forts F1 sur Structure, Water, Wetland, Cropland.

**Pertinence**  
Solution pratique au problème de cohérence temporelle sur imagerie aérienne historique hétérogène. Intègre GeoAI (U-Net + SAM) avec sources multiples pour analyse de changement haute résolution et planning paysager. Réutilisable pour d'autres séries aériennes ou drones.

**Actions recommandées**  
1. Lire le paper : https://arxiv.org/abs/2611.04470 (et version Landscape Ecology).  
2. Tester un pipeline similaire (U-Net/SAM + bridging) sur vos propres orthophotos ou Sentinel-2.  
3. Explorer l'intégration SAM dans des workflows QGIS ou Python (opengeos/geoai, etc.).

## 4. Plugins agents pour QGIS : Mapsuke (et alternatives) – contrôle chat de QGIS via Claude Code / Codex

**Résumé**  
Mapsuke (MIERUNE, open-source GPL v2) permet d'opérer QGIS par chat : l'agent (Claude Code ou Codex CLI) génère et exécute du code Python/PyQGIS/Processing. Support QGIS 3.44+ / 4.x, modes d'approbation (Ask/Auto/Full auto). Derniers updates ~30 oct. Discussions actives sur X et QGIS LAB. Alternatives : AI Agent by TerraLab, QGIS Agent, etc. Permet data acquisition → analyse → cartographie en langage naturel, et même upload vers services cloud (ex. Kumoy).

**Pertinence**  
Démocratise les agents GIS dans l'outil desktop open-source le plus utilisé. Réduit la courbe d'apprentissage et automatise les workflows répétitifs tout en gardant le contrôle humain. Complète les MCP servers (GIS Cloud, CARTO, etc.) et les agents cloud.

**Actions recommandées**  
1. Installer Mapsuke dans QGIS (plugins.qgis.org/plugins/mapsuke/) et tester avec Claude Code / Codex sur une tâche simple (ex. charger OSM + styliser).  
2. Lire les tutos QGIS LAB / MIERUNE et explorer les modes d'approbation.  
3. Comparer avec d'autres plugins agents (TerraLab) ou MCP externes pour vos workflows.
