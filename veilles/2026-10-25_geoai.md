## 1. Ai2 OlmoEarth v1.3 : embeddings satellite SOTA pré-calculés pour (presque) toute la planète

**Résumé**  
Le 22 octobre 2026, Ai2 a publié OlmoEarth v1.3. Le modèle compresse une année d’observations Sentinel-1 (radar), Sentinel-2 et Landsat en un vecteur (128-dim ou 64-dim) par pixel de 10 m. Les embeddings annuels pré-calculés sont disponibles globalement (hors Antarctique, 2023-2025 complets) avec l’**Embeddings Explorer** navigateur (sans inscription, sans GPU) pour comparer des années, trouver des lieux similaires, entraîner un classifieur léger et exporter en GeoTIFF. Performances supérieures à AlphaEarth Foundations et Tessera v2 sur la majorité des évaluations. Coût d’entraînement fortement réduit. Weights, code et données ouverts.

**Pertinence**  
C’est l’un des moyens les plus immédiats de faire du GeoAI sans GPU massif : prototypage de change detection, land cover, agriculture, mines ou risques en secondes. Complète parfaitement les agents (TerraLab, Google) en fournissant des features prêtes à l’emploi.

**Actions recommandées**  
1. Tester immédiatement l’Embeddings Explorer sur une zone de travail (https://olmoearth.allenai.org).  
2. Lire le blog et le technical report : https://allenai.org/blog/olmoearth-v1-3  
3. Exporter un GeoTIFF de classifieur simple et le charger dans QGIS pour validation.

## 2. TerraLab AI Agent pour QGIS : agent desktop performant sur les benchmarks Google

**Résumé**  
TerraLab a détaillé les performances de son plugin gratuit **AI Agent** pour QGIS sur les benchmarks GeoKTools et GeoExpertQueries de Google Research (octobre 2026). Il obtient 43,8/100 sur 41 questions publiques (Low effort), devant les setups Claude/GPT + MCP QGIS. L’agent trouve des données ouvertes, exécute des outils QGIS (centaines), style les couches et reste sous contrôle utilisateur (étapes visibles, undo). Free tier disponible.

**Pertinence**  
Concrétise l’agent géospatial dans l’environnement le plus utilisé par les géomaticiens open-source. Réduit la friction entre question en langage naturel et analyse spatiale réelle, avec traçabilité.

**Actions recommandées**  
1. Installer le plugin dans QGIS (Plugins → Manage and Install Plugins → « AI Agent ») et tester sur un projet existant.  
2. Lire la méthodologie et les scores : https://terra-lab.ai/blog/ai-agent-qgis-plugin-geospatial-benchmark  
3. Comparer à un workflow MCP (Claude Code / Cursor + QGIS MCP) sur la même tâche.

## 3. NATO teste des modèles IA pour le GEOINT en tant que service

**Résumé**  
Le 22 octobre 2026, AFCEA a rapporté que l’OTAN teste huit modèles d’IA sur son réseau classifié pour évaluer la fourniture de GEOINT as a service. Accent sur la traçabilité (références à l’IA dans les rapports, concept de « GEOINT AI assessment » / GAIA). Travaux avec Esri et BlackSky pour combiner imagerie drone + satellite en modèles jumeaux (digital twins). Mention du potentiel quantique pour accélérer le traitement de couverture 3D mondiale.

**Pertinence**  
Montre l’industrialisation et la gouvernance de l’IA dans le GEOINT défense/alliance : traçabilité, fusion multi-sources (satellite + drone), digital twins. Indicateur fort des standards et exigences qui vont percoler vers le civil.

**Actions recommandées**  
1. Lire l’article AFCEA : https://www.afcea.org/signal-media/international/nato-tests-ai-capabilities-within-geospatial-intelligence  
2. Réfléchir à la traçabilité des agents dans vos propres workflows (logs, sources, versions de modèles).  
3. Suivre les annonces Esri / BlackSky sur les jumeaux drone-satellite.

## 4. Fujairah lance un projet d’agents IA pour des modèles 3D urbains

**Résumé**  
Le 23 octobre 2026, le Fujairah Geographical Information Systems Center (FGISC) a annoncé le lancement d’un projet d’IA géospatiale basé sur des agents IA. Objectif : automatiser la création de modèles 3D des bâtiments gouvernementaux et des routes pour soutenir le planning urbain intelligent, améliorer la qualité des données et l’efficacité décisionnelle (digital twins).

**Pertinence**  
Exemple concret d’adoption gouvernementale d’agents IA pour la production de jumeaux numériques urbains. Utile pour qui travaille sur la 3D, le BIM, le planning ou les digital twins.

**Actions recommandées**  
1. Suivre les communications du FGISC pour détails techniques ou démos.  
2. Évaluer comment des agents pourraient automatiser une partie de votre pipeline 3D/urbain actuel.  
3. Comparer avec des outils open (ex. : agents + QGIS / CityGML / 3D Tiles).

## 5. NASA CASALS : LiDAR adaptatif + ML pour combler les trous des cartes 3D orbitales

**Résumé**  
Autour du 21 octobre 2026, NASA a mis en avant CASALS (Concurrent Artificially-intelligent Spectrometry and Adaptive Lidar System). L’instrument combine un LiDAR ultra-compact (steering par longueur d’onde, sans miroirs mécaniques lourds) et du machine learning pour balayer adaptativement de larges fauchées et combler les énormes lacunes des lidars spatiaux actuels (qui mesurent une ligne étroite). Tests aériens réussis (résolution ~21 cm). Conçu pour topographie, forêts, côtes, etc.

**Pertinence**  
Avance concrète vers des DEMs et structures de végétation 3D plus continues depuis l’espace. Le volet ML adaptatif (décision en orbite) est particulièrement intéressant pour l’IA embarquée.

**Actions recommandées**  
1. Lire les communiqués NASA / NTRS sur CASALS et les résultats aériens.  
2. Surveiller les futures campagnes ASCENT (2027).  
3. Réfléchir à l’usage d’IA adaptative dans vos propres pipelines de traitement LiDAR/drone.
