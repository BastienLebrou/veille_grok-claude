## 1. MAPL-EMIT (Google + NASA) : détection de panaches de méthane multipliée par ~1,5x

**Résumé**  
Un article récent (26 octobre) met en avant MAPL-EMIT, le modèle vision transformer (Swin-v2) développé par Google Research et NASA JPL. Entraîné sur 3,6 millions de panaches synthétiques injectés dans des scènes EMIT réelles, il détecte environ 50 % de panaches de méthane plausibles de plus que les analystes humains sur 1 084 granules, avec un recall élevé (~84 % sur les annotations expertes). Il fournit enhancement, masque de panache et localisation de source. Catalogue global disponible sur Earth Engine, poids sur Kaggle, code d’inférence sur GitHub. Publication PNAS.

**Pertinence**  
Exemple de pointe d’application de foundation/specialized models à l’hyperspectral pour un use-case climatique critique (méthane = fort potentiel de réduction à court terme). Montre comment l’IA peut scaler le monitoring de point sources au-delà des limites humaines, avec open data et outils réutilisables pour d’autres polluants ou phénomènes.

**Actions recommandées**  
1. Explorer le catalogue et l’app Earth Engine MAPL-EMIT pour visualiser des panaches.  
2. Tester le code d’inférence (GitHub) ou les poids Kaggle sur une scène EMIT si vous avez accès.  
3. Lire l’article PNAS et le blog Google Research pour les détails d’architecture et de validation.

## 2. GeoCore-9B (KAIST) : foundation model génératif géo-aware pour EO (NeurIPS 2026)

**Résumé**  
Annonce autour du 20 octobre : KAIST a développé GeoCore-9B, un modèle génératif de ~9B paramètres (Flow Matching DiT) entraîné from scratch exclusivement sur données EO (Git-10M, 10 millions de paires image-texte). Il conditionne sur texte + métadonnées géospatiales continues (lat/lon, GSD). Adapté via LoRA pour cloud removal et translation SAR-to-optical, où il surpasse des modèles spécialisés. Poids, code et page projet disponibles (Hugging Face / GitHub).

**Pertinence**  
Premier foundation model génératif de cette échelle nativement EO et « geo-aware » (contrairement aux fine-tunes de modèles naturels). Ouvre la voie à la restauration d’imagerie nuageuse, la synthèse multi-modale et des scénarios de simulation pour disaster response ou monitoring. Complète les embeddings (type OlmoEarth) par la génération.

**Actions recommandées**  
1. Cloner le repo KAIST-VICLab/GeoCore-9B ou télécharger les poids HF et tester une génération conditionnée (lat/lon + prompt).  
2. Lire le paper arXiv (2608.01896) et la page projet pour les benchmarks cloud removal / SAR.  
3. Comparer à des approches existantes (ex. SAR2Opt ou cloud removal classiques) sur un dataset public.

## 3. GenAI pour la visualisation de scénarios d’aménagement (Transactions in GIS, 25 oct.)

**Résumé**  
Publication du 25 octobre : « Generative Artificial Intelligence for Planning Scenario Visualization » (Qian Cao et al., UGA/UT Austin). Framework interactif GenAI + humain pour synthétiser des images street-level contrôlables de scénarios d’aménagement (ex. installations photovoltaïques) tout en préservant le contexte géographique. Benchmark de 11 configs sur 6 modèles, trade-offs réalisme / fidélité spatiale / alignement intention. Dataset before-after national, code GitHub à venir.

**Pertinence**  
Pont concret entre GenAI multimodale et pratiques d’urbanisme/planification spatiale. Montre comment intégrer street-view existant + prompts humains pour communiquer des alternatives. Utile pour digital twins, participation citoyenne ou visualisation rapide dans QGIS/ArcGIS.

**Actions recommandées**  
1. Lire le paper : https://doi.org/10.1111/tgis.70431  
2. Suivre le GitHub QianC95/planning-scenario-visualization pour le code.  
3. Tester un workflow similaire avec un plugin QGIS existant (ex. GeoPrompt Urban Scenario Visualizer) ou diffusion models + ControlNet sur une zone locale.

## 4. NATO : tests d’IA pour GEOINT-as-a-service avec traçabilité (GAIA)

**Résumé**  
Article AFCEA du 22 octobre : NATO teste 8 modèles IA sur réseau classifié pour offrir du GEOINT as a service. Insistance forte sur la traçabilité (tags, références au système IA). Futurs rapports assistés par IA nommés « GEOINT AI assessment » (GAIA). Travail avec Esri et BlackSky pour digital twins combinant drone + satellite. Mention de processing de couverture 3D mondiale et potentiel quantique.

**Pertinence**  
Illustre les exigences institutionnelles réelles (auditabilité, formation des analystes, intégration multi-sources) au-delà du hype. Pertinent pour qui développe des agents ou pipelines GeoAI destinés à des usages critiques ou réglementés.

**Actions recommandées**  
1. Lire l’article AFCEA complet pour les détails sur les tests et la vision.  
2. Réfléchir à l’implémentation de métadonnées de traçabilité dans vos propres workflows agents (ex. STAC-MLM ou logs structurés).  
3. Comparer avec les approches open (HOT fAIr, etc.) pour les standards de documentation de modèles.

## 5. Complément : preprint open sur classification d’arbres hors forêt avec Vision Transformers

**Résumé**  
Preprint récent partagé sur X : mapping et classification de trees outside forests (hedgerows, individual trees, groves vs forest) sur imagerie aérienne haute résolution en Allemagne. Les Vision Transformers surpassent les CNN grâce au contexte spatial. Dataset et code open source.

**Pertinence**  
Cas d’usage agricole/environnemental pratique où le contexte spatial (ViT) fait la différence. Renforce l’intérêt des architectures modernes sur données géospatiales haute résolution.

**Actions recommandées**  
1. Chercher le paper (Moritz Lucas et al.) et le code open.  
2. Tester une approche similaire sur des orthomosaïques locales (drones ou aérien).
