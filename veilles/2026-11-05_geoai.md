## 2. RemoteZero : raisonnement géospatial sans labels ni boxes (paper arXiv 2605.04451, mis en avant 5 nov.)

**Résumé**  
Paper de Hohai University et al. (soumis mai 2026, révisé août) : RemoteZero, framework label-free pour le raisonnement géospatial. Exploite le fait que les MLLM sont meilleurs à vérifier qu’à générer des boxes : prédiction de région → crop → vérification sémantique comme reward pour GRPO, avec self-evolution. Atteint 71,29 % Acc@0.5 sur EarthReason (test), battant le baseline supervisé RemoteReasoner (68,11 %) sans aucune annotation de box. Code : https://github.com/1e12Leon/RemoteZero.

**Pertinence**  
Attaque le goulot majeur du label bottleneck en Earth Observation. Permet d’entraîner ou d’améliorer des modèles de localisation/raisonnement sur des masses d’images non annotées. Direction clé pour scaler GeoAI sur données changeantes (changement d’usage, désastres, agriculture).

**Actions recommandées**  
1. Lire le paper : https://arxiv.org/abs/2605.04451 (HTML ou PDF).  
2. Cloner le repo GitHub et tester le code sur un petit jeu d’images EO non annotées.  
3. Réfléchir à l’intégration de la boucle vérification/self-evolution dans vos pipelines de fine-tuning MLLM géospatiaux.

## 3. ZenaTech : suite IA propriétaire pour traitement LiDAR drone (DaaS land surveying)

**Résumé**  
ZenaTech (annoncé fin oct., couverture 2 nov. 2026) développe ZenaAI, suite logicielle IA pour automatiser la classification de nuages de points LiDAR haute densité et l’extraction de features dans ses opérations Drone as a Service. Capacites prévues : classification DL (sol, végétation, bâtiments, lignes), génération DTM, vectorisation de linework (bordures, structures) vers CAD/BIM, filtrage de bruit et tagging d’assets. Objectif : réduire le post-processing de jours à minutes (jusqu’à -80 %).

**Pertinence**  
Exemple industriel d’automatisation du goulot post-acquisition LiDAR drone, critique pour surveying, infrastructure et BIM. Montre la maturation des pipelines GeoAI de bout en bout (acquisition → classification → livrable GIS/CAD).

**Actions recommandées**  
1. Lire les communiqués ZenaTech / Unmanned Systems Technology.  
2. Comparer avec des alternatives open (PDAL + modèles DL, ou agents sur nuages de points).  
3. Évaluer pour vos propres flux LiDAR drone : où le temps post-processing est-il le plus coûteux ?
