## Points (qualité > quantité)

### 1. GIS Cloud AI : croissance x2 + MCP natif vers Claude/ChatGPT
- Date : 8 octobre 2026 (IT Brief UK + site GIS Cloud)
- Résumé : Doublement de la croissance utilisateurs (>100 nouveaux/jour, total >220 000, >2 M cartes, 60+ pays). GIS Cloud AI (langage naturel sur maps/layers), serveur MCP + connecteurs ChatGPT/Claude (~55 outils : maps, layers, features, forms, queries, rendering…), AI Form Fill (photo/voix), App Builder. Assistant >50 000 interactions. Positionné comme multiplicateur au-dessus d’un GIS existant.
- Pertinence : Exemple commercial mature d’intégration LLM ↔ GIS via MCP (même pattern que CARTO, Esri, communauté QGIS). Démocratise l’accès aux données spatiales. Utile pour comparer architectures d’agents (outils exposés, confirmation humaine, gouvernance).
- Actions :
  1. Tester le MCP (compte free/trial) ou lire la doc : https://manual.giscloud.com/knowledge-base/gis-cloud-ai-mcp/ et https://www.giscloud.com/ai/
  2. Lister les outils MCP exposés et comparer à un MCP minimal (extent, layers, filter, export GeoJSON).
  3. Use-case : agent qui génère un rapport + carte interactive à partir d’une couche terrain existante.

### 2. OpenEarthAgent + GeoNatureAgent : agents tool-augmented et benchmarks MCP
- Date : OpenEarthAgent (présentation ECCV 2026, news ~9 oct.) ; GeoNatureAgent arXiv 6 oct. (2610.09112)
- Résumé : OpenEarthAgent (MBZUAI + IBM + TUM) = framework unifié d’agents géospatiaux tool-augmented (satellite, SAR, indices NDVI/NBR, opérations GIS). Modèle 4B compétitif avec GPT-5 sur certaines métriques. Dataset >100k reasoning steps. GitHub public. GeoNatureAgent (GNA) = framework/benchmark MCP (16 outils, 103 tasks) pour agents sur tâches environnementales (Espagne/Portugal). Claude Sonnet 4 ~61 %, DeepSeek V3.2 proche à coût bien inférieur. Code et API self-hostable publics.
- Pertinence : Passage de “copilot GIS” à agents qui planifient, appellent des outils spatiaux et raisonnent de façon traçable. Les benchmarks MCP deviennent le standard pour mesurer la capacité réelle.
- Actions :
  1. Cloner https://github.com/mbzuai-oryx/OpenEarthAgent + lire arXiv 2602.17665.
  2. Tester le harness GNA : https://github.com/gabrielireland/GeoNatureAgent_Benchmark (swap des tools pour ton domaine).
  3. Suivre les comptes liés et réfléchir à un petit agent MCP sur STAC + indices pour un use-case local.

### 3. Azercosmos Platerra : plateforme GeoAI pour imagerie satellite
- Date : 7 octobre 2026 (SatNews, Via Satellite)
- Résumé : Plateforme IA qui automatise le traitement d’imagerie EO : enhancement, détection forêt/végétation, mesure surfaces d’eau, détection d’objets/infrastructures, délimitation champs agricoles. Vise monitoring environnemental, agri et ressources.
- Pertinence : Cas classique de GeoAI “feature extraction” commercialisé par un opérateur satellite national. Montre la demande opérationnelle pour automatiser les volumes EO.
- Actions :
  1. Lire les annonces SatNews / Via Satellite et surveiller si une démo ou API apparaît.
  2. Comparer les capacités listées à des pipelines open (Segment Anything + indices, ou modèles Prithvi/Clay).
  3. Use-case : identifier une AOI agri/forêt et prototyper un équivalent avec outils open.

### 4. Safe Pro SPAI Ground Truth : suite AI drone + mapping de menaces
- Date : 8 octobre 2026
- Résumé : Suite 5 couches (Cloud, Air, Road, Field, NODE edge) fusionnant données drones aériens/terrestres pour détection de menaces (mines, UXO, drones d’embuscade, >150 types). Produit orthomosaïques, DSM, couches végétation/pente avec menaces cartographiées. Déjà traité 3,1 M+ images (Ukraine), 39k+ acres. Nouveau contrat US gov.
- Pertinence : Exemple concret d’AI computer-vision + produits géospatiaux (ortho, DSM) déployés en edge/real-time sur drones. Transférable à d’autres domaines (inspection, environnement, sécurité civile).
- Actions :
  1. Lire le communiqué Safe Pro et noter l’architecture (edge vs cloud, fusion multi-capteurs).
  2. Réfléchir à un pipeline similaire open : drone → détection (YOLO/SAM) → orthomosaic (WebODM) → couche vectorielle.
  3. Suivre les évolutions edge AI pour drones.
